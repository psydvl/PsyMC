# templatedatapack

Заготовка. Здесь будет шаблон датапака, который работает на нескольких версиях Minecraft сразу,
по тем же идеям, что и `../templatemod`.

## План

- **Один датапак на линию версий.** `pack.mcmeta` с диапазоном форматов: `supported_formats` до
  1.21.x и `min_format`/`max_format` в 26.x.
- **Различия версий через overlays** (с 1.20.2): общий слой и overlay-папки для отдельных
  диапазонов `pack_format`. Это аналог слоёв исходников мода (common → линия → пин). Типичные
  различия: `functions/` → `function/` в 1.21, изменения формата предметов (компоненты вместо NBT),
  переименованные реестры.
- **Сборка на Gradle (Kotlin DSL)**: zip датапака, подстановка версии и форматов из одной таблицы
  релизов (как `versionProperties/` у мода).
- **Проверки**:
  - выделенный сервер нужного релиза из launcher metadata, датапак в `world/datapacks/`;
  - `/datapack list`, `/reload`, вызов тестовой функции из консоли;
  - ошибки разбора JSON и функций в логе валят проверку, отчёт по релизам — как у `versionSmoke`.
- **Пример**: одна функция, один advancement, один рецепт, которые различаются между версиями.
- **Линтеры**: проверка JSON и mcfunction, форматирование.
- **Агентская обвязка**: `AGENTS.md` и `docs/`, как у мода.
