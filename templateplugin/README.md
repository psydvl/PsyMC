# templateplugin

Заготовка. Здесь будет шаблон серверного плагина, который работает на нескольких версиях
Minecraft сразу, по тем же идеям, что и `../templatemod`.

## План

- **Платформы**: Paper (и совместимые: Purpur, Folia), возможно Velocity для прокси. Список
  уточнится.
- **Пины и слои, как у мода**: общий код на API платформы и версионно-зависимые слои там, где API
  или внутренности сервера различаются между релизами. Один jar на линию версий.
- **Сборка на Gradle (Kotlin DSL)**: `plugin.yml`/`paper-plugin.yml` из шаблона, `api-version`
  из таблицы пинов; для внутренностей сервера — paperweight userdev с Mojang-именами.
- **Запуски**:
  - `runServer` с флагом `-Pplay`;
  - серверный smoke на каждом релизе линии: сервер стартует, плагин включается, консольный
    сценарий;
  - headless-клиент заходит на сервер, как в `serverSmoke` мода.
- **Пример**: одна команда, один слушатель событий, одна конфигурация.
- **Линтеры и форматтеры**: те же, что у мода (Spotless, Google Java Format, Error Prone).
- **Агентская обвязка**: `AGENTS.md` и `docs/`, как у мода.
